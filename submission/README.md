# C 题初赛 · 图书推荐可运行项目

**GitHub 源码版说明：** 以下是原比赛包的运行说明。Git 只提供源码、配置和参考校验值。若你持有完整比赛包，可直接解压运行；要在本源码目录运行，请从授权的本地比赛包补齐原有目录结构，包括 `inputs/`、`models/`，历史实验回放还需要 `evidence/` 和 `epoch_scores.csv`。这些文件不会被 Git 跟踪。

解压整个压缩包，在本文件所在目录运行。项目以 2025-09-01 为预测起点，按照官方验证清单的顺序输出“读者ID、推荐索书号列表”两列。每位读者获得十个以竖线分隔的索书号。

完整流程与代码对应关系见 [正式提交的建模过程](建模过程.md)。运行 `python replay_epochs.py` 可从借阅流水和归档的开发窗推荐复算轮数选择。

## 运行方式

已测试 Windows、Python 3.12、CPU。首次配置环境需要可用的 Python 依赖；模型权重、分词器、主题词表和本次比赛输入随包提供。建议使用虚拟环境。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe predict.py
.\.venv\Scripts\python.exe verify.py --check-reference
```

**快速预测**使用 models/event.pt 内的训练参数和书特征，从 work/processed/borrowing_cleaned.csv 重建基础统计，读取 inputs 中的官方读者清单与入藏目录，生成根目录的 验证集结果.csv。压缩包只保存参考哈希，预测文件由代码计算。自定义输出可用 `python pipeline.py predict --output result.csv`。

**从头训练并生成 CSV** 使用以下命令。默认用随包 Excel；第二种方式可使用组委会原始 Excel。两者均重新清洗、重建书目、从随机初始化训练双塔、保存参数和输出推荐。命令会更新解压目录中的模型、加工数据和结果文件。

```powershell
python train.py
# 或使用组委会原表
python pipeline.py train --raw "D:\比赛数据\2022-2025处理后借阅信息.xlsx"
python verify.py
```

训练使用种子 2026、CPU 单线程与确定性运算。开发窗取三个固定时间点、两个种子评估 8、12、16 轮，按实际提交分流合并新人与老人得分，等权平均分别为 7.834、7.725、7.715，选择 **8 轮**。各窗口和种子的得分保存在 epoch_scores.csv，正式训练损失和截止日期见 models/event_manifest.json。历史开发回放分仅用于选参。参考哈希用于检验发布参数的预测；不同 PyTorch、数值库或硬件上的重新训练可能产生数值差异。

## 数据与模型

- inputs/2022-2025处理后借阅信息.xlsx 使用原始工作表布局。随包副本对操作员和操作员 IP 做等值代号替换，保留去重关系；建模用的 13 个字段已与原表清洗结果逐行核对。
- preprocess.py 清洗借阅操作、时间和编号。build_book_catalog.py 整合借阅书目、中文入藏（新书）.csv 和验证集发放.csv 的历史书单，按索书号合并，保留题名与责任者冲突标记。inputs/topics.jsonl 和 book_topics_v2.json 提供已有的多主题标注。
- 训练标签来自预测截止前的借阅流水。同读者相邻借阅间隔不超过 30 分钟合成事件。GRU 读取事件序列，联合学习下一事件与两个月窗口中的首次新借索书号，每批 96，每个有效查询 1 个正例和 12 个负例。
- 冻结的 BGE 中文题名编码器、分词器和来源版本在 models/bge/。输入的排序题名与版本指纹匹配时，可从随包权重复用题名向量；变更后使用本地 BGE 编码。书塔融合题名、责任者、分类、出版社、出版年代和主题。读者塔融合最近历史与五项画像。训练流水中的截止后互动不参与拟合。官方清单提供预测时可见的画像、历史书单和最近借阅日期。
- 有历史读者使用基础榜与事件榜，分别取前 100 个候选，以权重 1 和 0.5、倒数排名常数 20 融合。冷新人使用原提交的六属性群体偏好与热门回退，无历史老人使用近期热门。可推荐范围为训练历史与新入藏目录中的合法索书号，个人历史书单中的索书号全部排除。
- 变更训练数据、入藏元数据或超出模型书库的书单时，请重新执行 train。verify.py 独立检查本届 956 名读者、顺序、十本去重、合法书目和历史排除。reference.sha256 为本次发布 CSV 的 SHA-256。

本机实测依赖包括 Python 3.12.14、PyTorch 2.14.1+cpu、NumPy 2.3.5、pandas 3.0.1、transformers 4.57.6、openpyxl 3.1.5 和 safetensors 0.7.0。requirements.txt 给出兼容安装范围；使用已配置项目环境时可直接执行上述脚本。

## 新入藏图书在此次结果中的位置

正式候选库含 7,068 个仅在新入藏目录出现的索书号。345 位有历史读者中，199 人的事件通道前十出现了这类书；通道前百覆盖全部 345 人，共含 1,020 个不同的新入藏独有索书号。最终 CSV 中这类书占 0 个位置。基础榜来自历史借阅，有至少十本候选时，第十名仅基础分已达 1/30，新书独靠事件榜第一名最多得到 0.5/21。这个已开发验证的轻融合配置主要重排基础榜，适用范围见上述统计。
